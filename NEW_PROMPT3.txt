def validate_phone(phone):

### Python reference

```python
from datetime import datetime
from zoneinfo import ZoneInfo

PH_TIMEZONE = ZoneInfo("Asia/Manila")

def validate_trip_date(value, input_format="%Y-%m-%d"):
    if not isinstance(value, str) or not value.strip():
        return None, "Please select a trip date."

    value = value.strip()

    try:
        selected_date = datetime.strptime(
            value, input_format
        ).date()

        if selected_date.strftime(input_format) != value:
            return None, "Please enter a valid date format."

    except ValueError:
        return None, "Please enter a valid calendar date."

    today = datetime.now(PH_TIMEZONE).date()

    if selected_date < today:
        return None, "Trip date cannot be in the past."

    return selected_date, None
```

Use `%Y-%m-%d` for native date inputs.

Only use `%m/%d/%Y` when the actual field requires MM/DD/YYYY text input.
